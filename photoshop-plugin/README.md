# Ecko Tone panel for Photoshop

A UXP panel that halftones the selected layer and puts the result on a new layer at the same
position. **It runs entirely inside Photoshop**, with no server and no internet. It uses the
same engine as the stand-alone web page (`dist/ecko-tone.html`), and your document's
resolution as the DPI.

It has the same settings as the web page: presets and Simple process; art clean-up (background
removal, specks, smoothing, sharpen); every colour mode and pattern; threshold tones with their own
cut points; palettes, spot colours and ink colours; white underbase and its choke; tone (brightness,
contrast, midtones, black and white points, invert); procedural textures plus your own texture taken
from any layer; shirt colour (presets or any hex) and Fit to shirt; borders; and press control
(dot sizes, dot gain, rough edges, misregistration, registration marks).

**Vintage & bootleg**: a keyline and drop shadow around the whole design (auto or any colour), a ghost /
slur double print, and wear textures (washed out, fabric weave, squeegee streaks, screen pinholes, plus
worn, cracked, grunge, scratches, toner). Presets: Bootleg rap tee, Flea-market bootleg, Sun-faded 80s,
Thrashed band tee.
See [the sample sheet](../docs/vintage-looks.png).

**Scanned textures**: 16 knockouts made from scans of real worn prints (cracks, crackle, crazing, scuffs, heather and linen). They tile without seams and work the same on light and dark shirts. See [the scanned textures sheet](../docs/scanned-textures.png).

**Full view** (button at the top right of the panel) switches to the web app's layout: settings on the left,
a live preview on the shirt colour in the middle (Print / Original tabs), and Inks, Download and Print check on
the right, with shirt swatches on top. Float the panel (drag its tab out) and make it as big as you like; XL
makes the columns tall. **Compact** switches back.

After Apply, the **Inks** list works like the web page's: switch each ink on or off, solo it, choke or
spread it, recolour spot inks, and give each ink your own name. Inks are named by colour
("Red", "Navy", "Athletic gold"…) until you rename them.

**Live editing** (pause or resume with its button) repaints the result layer as you change settings.

Separations: **Make layers** puts one layer per ink in a group; **Save films…** writes one 1-bit PNG
per ink and a README to a folder you pick. Layers, film files and the README all carry each ink's name
and colour. Text, mockups and batch are in the web page (use Photoshop's own type tool here).

**Status: experimental.** It hasn't been run inside Photoshop yet. The engine it uses is tested
(`node --test tests/js/engine.test.js`) and matches the Python engine's results.

## Install with the .ccx (one file)

`dist/ecko-tone.ccx` is Adobe's plug-in package. Double-click it, and the Creative Cloud app installs
it (accept the warning that it isn't from the Adobe store).

If your Mac shows it as a plain document, the Creative Cloud plug-in installer isn't linked to `.ccx`
files. Install it from Terminal instead (one line; adjust the path if the file isn't in Downloads):

    "/Library/Application Support/Adobe/Adobe Desktop Common/RemoteComponents/UPI/UnifiedPluginInstallerAgent/UnifiedPluginInstallerAgent.app/Contents/MacOS/UnifiedPluginInstallerAgent" --install ~/Downloads/ecko-tone.ccx

## Install with UXP Developer Tool (folder)

1. Install Adobe's **UXP Developer Tool** from the Creative Cloud app (free).
2. In UXP Developer Tool: *Add Plugin* → choose this folder's `manifest.json` → *Load*.
3. In Photoshop: *Plugins → Ecko Tone*. Select a layer, pick a look and a shirt colour, and
   click **Apply to selected layer**.

Needs Photoshop 2023 (v24) or later and an RGB document. `tone-engine.js` is generated by
`python tools/build_standalone.py`; don't edit it by hand.
