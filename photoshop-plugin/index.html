Output
Layers: one layer per ink in a group, in print order (first ink at the bottom), named with the ink name and colour.
Films: one 1-bit PNG per ink (black = ink) at your document's DPI, named with the ink name and colour, plus a README with each ink's name, hex, RGB, angle and coverage.
Inks switched off are skipped. For the full-colour print file, use File › Export on the result layer.
